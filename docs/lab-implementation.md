## 2. 逐条规格

### 2-1 样本

```js
state.samples = { [dexId]: 份数 }
```

- 全局只有一种「样本」，但**按物种分开计数**：烈雀样本只能造烈雀。
- 新档初始化为 `{}`。

### 2-2 终末榨取

**可用条件**：该物种研究 100%（`isResearched`），且实验台里有一只活着的个体。

**效果**：

```
扣耗材 → 产出样本 → 个体死 + 留遗体 → 台子仍被遗体占着
```

**产出**（正态分布，种子化 LCG，两次 `random()` 做 Box–Muller）：

```js
μ = max(1, 当前耐受 / 50)
σ = max(0.6, μ × 0.3)
数量 = clamp(round(μ + σ × gauss()), 1, ceil(μ × 2))
```

| 当前耐受 | μ | 常见区间 |
|---|---|---|
| 100 | 2.0 | 1–3 |
| 158 | 3.2 | 2–4 |
| 218 | 4.4 | 3–6 |

- 用**当前剩余耐受**，不是上限（先拿去繁育/实验过的个体，榨出来更少）。
- 不保底低端（完整正态）。
- 遗体沿用现有规则：占位、6 金处理。

**文案**（结构二）：

```
┌──────────────────────────────────────────────┐
│ 终末榨取                           🪙 180     │
│ 此前完成的是「应激阈值」                        │
│ 不再记录反应，也不再抢救：从旧伤口下刀，把还能用的部分逐件取下。│
└──────────────────────────────────────────────┘
```

- 结果卡标题：`处置完成 · 样本已耗尽`
- **不显示**预计样本数，**不写**任何说明文字（§14.7）

### 2-3 实验室助手

**状态**（挂在实验台上）：

```js
state.lab[i] = { uid, corpse, assistant: false, auto: false, spend: 0 }
```

| 字段 | 含义 |
|---|---|
| `assistant` | 这个台子有助手在负责（占用中） |
| `auto` | 助手正在自动研究（可被「打断」关掉） |
| `spend` | 耗材费的零头累加器（见下） |

**可用条件**（三个都要满足）：

1. 该物种的 **5 条实验全部亲手做过**（`expLog[dexId]` 里每条都有记录）
2. 有空闲助手（未被占用的台子数 < 助手数量）
3. 该物种研究未满 100%

**速率**（对齐 harsh 档）：

| 资源 | 每秒 |
|---|---|
| 研究进度 | **0.5** |
| 耐受 | **3.86** |
| 耗材 | **6.4 金** |

**tick 逻辑**（每个 dт 对每个 `auto` 的台子）：

```
个体不存在 / 研究已满        → auto = false
资金不足                    → 本 tick 不推进（暂停，助手仍占用）
否则：
  进度 += 0.5 × dt
  耐受 -= 3.86 × dt
  耗材  += 6.4 × dt（攒够 1 金才真正扣）
  耐受 ≤ 0                  → 死亡 + 留遗体 + auto = false（assistant 仍占用）
  进度够 100%               → 研究完成，auto = false（assistant 仍占用）
```

- 进度与耐受都**连续变化**，不模拟离散实验，不跑冷却。
- 耗材用 `spend` 累加零头，攒够整数再扣，避免浮点误差。

**打断**：`auto = false`，`assistant` 保持。玩家可手动做该物种的任意实验（含非首次）；之后可重新开启自动。

**助手占用何时释放**：台子清空（遗体处理掉 / 个体消失）时才释放。

**助手数量**：

| 职级 | 助手数 |
|---|---|
| 0–2 | 0 |
| 3 · 高级研究员 | 1 |
| 4 · 首席研究员 | 2 |
| 5 · 干部 | 3 |

```js
assistantSlots = clamp(rank - 2, 0, 3)
```

### 2-4 实验「费用」改称「耗材」

实验室相关文案里，实验的 🪙 支出统一叫**实验耗材**（试剂、容器、电）。数值不变。

### 2-5 实验日志组头去掉「N 次」

现状：`#0042 烈雀 Lv.58 3 次`
改为：`#0042 烈雀 Lv.58`

### 2-6 实验日志的助手节点

| 事件 | 记录 |
|---|---|
| 安排助手开始自动研究 | 「安排助手对其进行实验」 |
| 玩家打断、接管 | 「你决定亲自动手」 |
| 个体在助手阶段死亡 | 沿用「实验结束后对象死亡」 |

- 只记这三个节点，**不逐条记录自动研究的进度**。
- 研究到 100% 不额外记日志（沿用「研究满后不写日志」）。
- 图鉴只给总数（损耗 N / 研究成本），**不拆亲手 / 助手**。

### 2-7 100% 之后的行为

- 个体详情与实验台卡片：不再提供「实验」按钮
- `startExperiment` 对已研究物种直接拒绝
- 改为提供**终末榨取**

## 6. 手动验收

1. 新档，把某物种 5 条实验各亲手做一次
2. 再放一只该物种进实验台 → 出现「安排助手」
3. 安排后进度开始自己涨、耐受自己掉、金币自己减；卡片显示「助手研究中」
4. 点「打断」→ 停止推进，助手仍占用；可手动做实验；可再开自动
5. 让助手把它用死 → 遗体占位，助手仍占用；处理后助手释放
6. 把该物种刷到 100% → 出现「终末榨取」，「实验」消失
7. 终末榨取 → 个体死、产出样本、遗体占位

## 8. 实施记录（2026-11-20）

7 条全部落地，`npm test` 五套全绿。

### 8.1 与清单的偏差

| 项 | 情况 |
|---|---|
| `labSignature` | 实现时发现必须把 **`speciesHandled`（5 条是否都做过）** 也算进签名——否则玩家做完第 5 条实验后，「安排助手」按钮仍停在禁用状态 |
| 遗体槽位的终末榨取 | 提示改为「实验台上只剩遗体」（原清单只写了“实验台是空的”，对遗体槽位是错的） |
| 打断后 | 补了一个 `resumeAssistant`：打断不是终点，可以随时再交给助手（清单里只写了“可以随时交还”，实现时补成显式接口） |
| 样本的界面 | **没有做**——它目前唯一的消费端是克隆，等那个系统再给展示位置 |

### 8.2 实测数值

一个 Lv.40 雄性（耐受上限 223）交给助手：

```
56 秒后耐受归零 → 研究 71%、耗材 360 金、遗体占位、助手仍占用
```

助手单次能推出约 35 点进度（波波需求 40），也就是说**一个助手 ≈ 一次半的物种收尾**。
