# 规则现状（Reference）

> 类型：reference（查事实）｜ 更新：2026-11-24
> 这是**唯一现行规则来源**。数值以 `js/rules.mjs` 为准；本文件与代码不一致时，必须在同一次提交里两边对齐。
> 为什么这样设计 → [`design/`](design/)；玩家怎么读 → 游戏内「玩法说明」。

## 0. 基础约定

| 项 | 现行 |
|---|---|
| 时间 | 1 游戏日 = 12 秒真实时间（`CONFIG.secondsPerDay`）；顶栏可切倍速 |
| 自动暂停 | **只有「研究笔记」页暂停**（`AUTO_PAUSE_TABS = ['dex']`）；实验室不暂停 |
| 存档 | `SAVE_VERSION = 7`，key `rocket-simulator-save-v7`；**不写迁移**，版本不符直接丢弃 |
| 开局 | 1800 资金、12 颗糖果、3 个培育栏；波波 ♂ + 两只无亲缘烈雀 ♀ |
| 等级 | 上限 60（`CONFIG.maxLevel`） |

## 1. 繁育

| 项 | 值 |
|---|---|
| 繁育条 | 2.5 天满（`breedDays`） |
| 正常产蛋成本 | 承担方 −40 耐受（母方；无雌性时是百变怪） |
| 跨蛋组成本 | 母 −44、父 −12（父方同样会力竭） |
| 跨蛋组死胎率 | 30%（`crossGroupStillbirth`） |
| 雌雄判定 | 必须一雄一雌；同性在选择器里不列出 |
| 蛋组不匹配 | 直接走跨蛋组流程（见 §3），不锁对 |
| 繁育条满但孵化器没空位 | 停 100% 等待，不掉耐受 |

放置限制（`assignPen()`）：**未发现蛋组的物种、双百变怪直接拒绝放入**；同性在选择器里不列出；其余可放。

放入后仍配不上的（`compatibility()` 返回静默）：不孕/不育（显示原因）、无性别、同性（选择器不列出，正常不会出现）。

「静默」= 繁育条归零、无产出、不掉耐受、不写日志。

### 1.1 近亲与体质

| 关系 | 深度 | 乘数 |
|---|---|---|
| 直系（亲子 / 祖孙 / 曾祖孙…任意代数） | 任意 | 0.70 |
| 全同胞 / 半同胞 | 1 | 0.78 |
| 叔侄 / 表亲 | 2 | 0.88 |
| 二代表亲 | 3 | 0.95 |
| 三代以外 | ≥4 | 不惩罚 |

- 近亲：`子代体质 = min(双亲) × 乘数`，下限 0.5
- 非近亲：`子代体质 = 双亲均值 + 0.2`，封顶 1（换血）
- 乘数 ≤0.95 才标「近亲」（选择器徽标）
- 体质乘在**耐受上限**上（`maxTolerance()`）
- 死胎率跟体质走：≥0.85 → 0%，≥0.72 → 2%，≥0.61 → 4%，其余 6%；死胎照常扣耐受

### 1.2 产蛋与力竭顺序

先结算产出（或死胎），**再**判力竭——最后一胎不会被吞掉。

## 2. 蛋与孵化

| 项 | 现行 |
|---|---|
| 孵化天数 | `clamp(hatch_counter / 6, 2, 10) × (1 − 0.1 × 孵化器等级)`，最少 1 天 |
| 蛋位 | 2 + 孵化器等级 |
| 孵出形态 | 永远是家族最初形态（沿 `evolvesFrom` 回溯） |
| 孵出位置 | **默认进围栏**，不自动进培育栏 |
| 蛋卡 | 只显示物种 + 剩余天数；父母/来源在详情里 |
| 蛋 | **不能丢弃、不能出售** |
| 蛋价 | `round(valueOf(dex) × (0.95 + rand × 0.2))` |
| 来源 | 30 地点 × 10 手段 = 300 条，跟着蛋 → 个体走完一生 |

## 3. 畸形体

| 项 | 现行 |
|---|---|
| 来源 | 跨蛋组繁育存活下来的后代 |
| 体质 | 0.5（耐受上限减半） |
| 繁育 | 不育；**不能放进培育栏**（选择器不列出，`assignPen()` 拒绝） |
| 图鉴 | 无条目、不占图鉴 |
| 研究 | 不推进任何物种研究，放进实验室也做不了实验 |
| 交单 | 禁止（交付列表过滤） |
| 售价 | 同物种普通个体的 17%（`mutantSellFactor`） |
| 终末榨取 | 固定 1 份样本（不受耐受影响） |
| 围栏 | 单独「畸体」段；不参与霸凌 |
| 立绘 | 母方图 + 湍流扭曲；参数（seed / 位移 / 频率 / 色相 / 饱和度 / 对比度）由**个体 uid** 派生，同一只固定、彼此不同 |

## 4. 围栏

- 开关三段：**培育相关 / 其它 / 畸体**；畸体段只在存在畸形体时出现，不重复出现在「其它」里。
- 培育相关 = 培育栏里的物种 + 其整条进化链。
- 霸凌：同种同性别达到 4 只后，**最弱的一只**每天掉 `3 × (只数 − 3)` 耐受；百变怪不参与。
- 霸凌致死 → 围栏「遗体」栏，处理费 6 资金；培育栏 / 实验室死亡同样是 6 资金。
- 驻守位 4 个：占位，未启用。

## 5. 实验室

| 项 | 现行 |
|---|---|
| 实验台 | 初始 2，上限 4 |
| 研究要求 | `round(40 + (255 − capture_rate) × 1.4)`（波波 40、梦幻 334） |
| 实验数量 | 专属 2–8 条；不足 5 条按 对战 → 采样 → 体测 补到 5；按强度升序 |
| 资金倍率 | 所有实验花费 ×1.5（`experimentCostMultiplier`） |
| 冷却 | 按「个体 + 实验」独立，按真实秒计 |
| 放进去 | **取不出来**，只能继续实验或付费处理 |
| 活体处理费 | `8 + 剩余耐受 × 0.12` |
| 遗体处理费 | 6 |
| 挣扎 | 耐受 >70 时每天 −2，降到 70 停 |
| 威胁 | harsh 档或损耗 ≥ 自身上限 50% 时，同实验室其他个体 −6% 上限；耐受不足上限 10% 的不受影响 |

### 5.1 基础三条（`BASE_EXPERIMENTS`）

| 实验 | 进度 | 原价 | 实付（×1.5） | 冷却 |
|---|---|---|---|---|
| 基础体测 | 2 | 10 | 15 | 5 秒 |
| 组织采样 | 4 | 30 | 45 | 10 秒 |
| 对战测试 | 8 | 60 | 90 | 16 秒 |

### 5.2 专属档位（`EXPERIMENT_TIERS`）

| 档位 | 进度 | 原价 | 实付（×1.5） | 冷却 |
|---|---|---|---|---|
| gentle | 3 | 20 | 30 | 6 秒 |
| standard | 7 | 55 | 82.5 | 14 秒 |
| harsh | 14 | 120 | 180 | 28 秒 |

### 5.3 研究 100% 之后

实验关闭，只剩两项操作：

- **终末榨取**：180 资金，必死，遗体照旧 6 资金处理。
  - 样本数：`μ = 耐受 / 50`，`σ = 0.3μ`，上限 `2μ`，最少 1；按物种分开计数。
- **处理**：活体 / 遗体同上。

### 5.4 实验室助手

| 项 | 现行 |
|---|---|
| 解锁 | 职级 3；职级 4、5 各 +1，最多 3 个 |
| 条件 | 该物种 5 条实验**全部亲手做过** |
| 速率 | 0.5 进度 / 3.86 耐受 / 6.4 资金 每秒 |
| 停止 | 进度满 100% 自动停，但仍占台，直到处理遗体 |
| 打断 | 随时可打断；打断后助手仍占位，可再做实验或交还 |
| 日志 | 只记「安排助手对其进行实验」「你决定亲自动手」两条 |

### 5.5 实验日志与结果文案

- 日志只显示行为 + 生还/死亡；物种详情显示最近 10 条。
- 研究完成的那条日志高亮；**该物种 100% 后不再记录任何实验日志**。
- 死亡后处理遗体不重复计损耗 / 日志。
- `data/results/` 与 `js/results.mjs` 保留但**不加载、不展示**。

## 6. 耐受度

- 上限：`(100 + (等级 − 1) × 2) × (雄性 ? 1.25 : 1) × 体质`
- 出厂即满；升级同步补差；**只有进实验室才在界面上显示**。
- 消耗：繁育、霸凌、实验；归零即死亡。
- 死亡落点：实验室 → 遗体占台；培育栏 → 遗体占位；围栏霸凌 → 遗体栏；其余离队。

## 7. 个体特质

| 特质 | 概率 | 效果 |
|---|---|---|
| 闪光 | 1/4096 | 纯视觉（金色光晕 + ✨） |
| 不孕（♀）/ 不育（♂） | 2/4096 | 无法配种 |
| 近亲标记 | 体质乘数 ≤0.95 | 选择器显示「近亲」 |

IV 0–31 仍参与能力值计算，但**不展示**；繁育取双亲均值 ±5。

## 8. 能力值披露

六项能力按**种族值从高到低**逐项披露，进度每约 16.7% 披露一项，100% 全公开。个体值不展示。

## 9. 部门需求

| 项 | 现行 |
|---|---|
| 生成 | 每 2.4 天（`orderIntervalDays`）一条 |
| 类型 | 任意 / 属性 / 指定物种 |
| 期限 | `5 + 0.35 × 最低等级 + rand × 4` 天；总裁办 ×0.75 |
| 报酬 | 基础 `150 + 等级×50 + 稀有度` × 类型系数 × 声望加成 × 广告牌加成 × **0.4**（总裁办 **×3.2**） |
| 声望 | 普通 +4；总裁办 +13 |
| 总裁办概率 | 2% + 每职级 1.2% |
| 过期/回绝 | 不扣声望 |
| 声望流失 | 距上次完成 >3 天后，0.5/天起，闲置每多 1 天 +0.1/天 |
| 可交付 | 只限**围栏里闲置**、非畸形体、满足条件的个体 |

## 10. 经营、设施与职级

- 蛋贩子：每 14 天自动换货；「换一批」60 起，每换一次 +25，按天回落 8/天，上限 300。蛋只标蛋组与来源。
- 道具价：进化石 520（叶/月/日/冰 620）、通信电缆 900。
- 糖果：基础 14，按批次浮动；每颗 100 经验。
- 经验：培育栏 26/秒、围栏 7/秒；训练场提升被动经验。

## 11. 研究笔记

- 格子三态：未研究（剪影 + `???`）/ 有进度（灰度 + 百分比）/ 100%（彩色）。
- 顶部只汇总**实验总成本**与**累计损耗**，不展示研究记录列表。
- 物种详情：属性、蛋组、种族值、进度、损耗、研究成本、研究笔记描述（100% 才揭晓）。
- 蛋组只在该物种**研究 100%** 时揭示；繁育不再透露蛋组。

## 12. 收束

151 个物种研究全部完成 **或** 职级达到干部 → 收束；也可随时「离开火箭队」认输。收束后仍可继续经营。

## 16. 隐性设定（不向玩家明示）

> 来源：README「隐性设定」表（2026-11-24 迁入）。原则：界面只给结果与现象，不给公式、概率和判定条件。
> 现状例外：帮助弹窗仍保留一部分数值（繁育成本、闪光概率、霸凌阈值、畸形体售价），后续按本表逐步收敛。

| 设定 | 界面表现 | 出处 |
|---|---|---|
| 蛋组未知 | 只显示 `？？？`；该物种研究 100% 才揭示 | `logic.eggGroupsDisplay` / `addResearch` |
| 耐受度上限与等级、性别、体质挂钩 | 只有进实验室才显示数值，培育栏 / 围栏只靠灰度暗示 | `rules.toleranceCap` / `maxTolerance` |
| 体质系数（近亲退化） | 不显示数值，只体现为耐受灰度更短、产胎更少；配对只标「近亲」，且只在乘数 ≤0.95 时标 | `logic.childVigor` / `kinTier` |
| 死胎概率 | 不预告；只在发生时说「这一胎没有成型」 | `logic.stillbirthChance` |
| 能力值按研究进度披露 | 未披露项显示 `？？？`，不显示披露进度计数 | `logic.revealedStats` |
| 个体值（IV） | 物种研究 100% 之前不展示，之后在个体详情页显示 | `ui.statRowHtml` |
| 研究满 100% 后不再产出日志 | 之后的实验、死亡、处理都不进日志，界面不解释 | `logic.logExperimentRun` 等 |
| 实验的真实影响 | 只标资金与冷却，不预告耐受损耗与致死风险 | `logic.toleranceLoss` |
| 终末榨取的产出 | 不预告数量，只在结果里给出实际份数 | `logic.finalExtraction` |
| 助手的速率 | 只显示「助手研究中」，不展示每秒进度 / 耐受 / 耗材 | `rules.CONFIG.assistant*` |
| 实验结果文案 | 暂不展示；生还 / 死亡由真实结果决定 | `data/results/*` |
| 配对能不能成 | 条满才知道；界面不提前说明蛋组是否匹配，同性不列出 | `logic.compatibility` / `assignPen` |
| 畸形体的判定 | 不说「这是跨蛋组生的」，只表现为不育、体质弱、卖价低 | `logic.createEgg` |
| 闪光 / 不孕不育概率 | 只显示结果（徽章 / 光晕），不写概率 | `rules.CONFIG.shinyChance` |
| 繁育遗传规则 | 不解释 IV 均值与性格继承 | `logic.createEgg` |
| 血统与近亲 | 只在**配对选择器**给亲属称呼（哥哥、表妹、叔叔……）；不给档位、乘数、距离；详情页不显示血缘 | `logic.kinLabel` |
