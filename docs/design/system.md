## 12. 全系统梳理（2026-11-20，讨论中）

> 换一个视角：不看单个系统，看**资源怎么流动**。只记录事实与判断，未定的不写成决定。

### 12.1 资源流

### 12.3 结构性问题

| 级别 | 问题 | 证据 |
|---|---|---|
| P0 | **研究是纯消耗** | 不产资金、不产声望、不产道具，只产图鉴条目与信息解锁 |
| P0 | **声望单源** | 只有交付订单给声望；研究 151 个物种对职级零贡献 |
| P0 | **两条收束线差约 10 倍** | 职级约 60–100 单（2–4 小时）vs 151 研究约 600–1,000 单（20+ 小时） |
| P1 | **个体没有质量出口** | 卖价低于蛋价；订单不读质量；实验只消耗 |
| P1 | **时间尺度失真** | 1 天 = 12 秒；繁育 30 秒、孵化 24–120 秒，"天"级设计体感极弱 |
| P2 | **没有阶段目标** | 收束只有两个终局判定，中间只有 6 档职级 |

### 12.4 目标时长：8–10 小时（✅ 2026-11-20 决定）

一局 8–10 小时 ≈ 480–600 分钟 ≈ **2,700 游戏日**（1 天 = 12 秒）。

按 9 小时做的预算表：

| 项目 | 目标 | 现状 | 差距 |
|---|---|---|---|
| 研究总点击 | 2,000–2,700 | 2,679 | ✅ 基本合适 |
| 研究墙钟（2–4 台并行） | 5–10 小时 | 2 台 10.4 h / 4 台 5.2 h | ✅ 合适 |
| 研究总费用 | ~100k | **482k** | ❌ 约 4.8 倍 |
| 一局订单总数 | 350–400 | 上限 1,125（2.4 天刷新） | ❌ 供给太快 |
| 声望满级所需订单 | ~230 单 | **23 单** | ❌ 快 10 倍 |
| 总资金需求 | ~260k | — | |
| 总操作次数 | ~3,500 | — | 约 6.5 次/分钟 |

**结论**：研究的**点击量与墙钟**已经落在 8–10 小时里，不用大改；真正超标的是一道**几乎并行的第二道闸门**——研究费用（482k），以及订单/声望在长局里会瞬间打满。

#### 建议的重标定（未拍板）

| 项 | 现值 | 建议 |
|---|---|---|
| 订单刷新间隔 | 2.4 天（29 秒） | **7 天（84 秒）** |
| 声望刻度 | 0–100，23 单到顶 | **0–1000，约 230 单到顶** |
| 职级阈值 | 18 / 36 / 55 / 75 / 92 | ×10 |
| 声望衰减 | 0.5–5 / 天 | ×10（同比例） |
| 实验费用 | 180 / 82 / 30 | ×1/4 → 45 / 20 / 8 |
| 研究完成回报 | 无 | 返经费 = 需求 × 0.5（合计约 19k） |

### 12.5 金币来源核对：繁育 → 出售（2026-11-20，实测反馈）

> 玩家实测：**金币很容易获取，一直"繁育 → 出售"就够了**。这条推翻 §12.4 的收入模型（那里只算了订单）。

| 环节 | 数字（以烈雀为例） |
|---|---|
| `valueOf` | 200 + bst×0.9 + (255−捕获率)×1.2 = **436** |
| 卖价 Lv.1 / Lv.60 | 0.85~1.75 倍系数 × 0.45 → **170 / 343** |
| 育种成本 | **0 金**，只占栏位 30 秒（母体耐受 −32） |
| 孵化 | 24–120 秒，蛋位 2–5 |
| 吞吐 | 早期约 2 只/分 → **340 金/分**；后期约 7 只/分 → **1,200 金/分** |
| 9 小时累计 | 约 **18 万 – 64 万金** |

**结论**：出售**无门槛、无上限、接近被动**，所以它成了最优解。订单被降级成"顺手交一下"，职级 5 万、研究 48 万都能这样刷出来。

**修正 §12.4**：之前"研究费 482k 超标 4.8 倍"的判断**作废**——以卖养研时，482k 恰好就是 9 小时的量级。真正的问题不是数值不够，而是**数值把玩家推向了一个没有决策的循环**。

## 16. 样本、复刻与传说宝可梦（2026-11-20，讨论中）

### 16.1 传说宝可梦：每只一个专属任务（✅ 方向）

| # | 决定 | 内容 |
|---|---|---|
| 16-1 | ✅ **传说不进繁育/市场/复刻** | 每只传说单独设计一个获取玩法（任务），因为它们足够特殊 |
| 16-2 | 🕒 **暂缓实施** | 工作量预估较大，先把方向记下来 |

**现状事实**：5 只传说/幻兽（急冻鸟 144 / 闪电鸟 145 / 火焰鸟 146 / 超梦 150 / 梦幻 151）**目前完全无法获得**——市场排除了 legendary/mythical，它们又是「未发现蛋组」无法繁育。
所以现在**图鉴收束是不可达的**，唯一通关路径是最高职级。

### 16.2 样本：物种绑定，不做通用研究进度（✅ 方向）

曾考虑"样本 = 通用研究进度"，用于救济稀有物种。放弃，原因是：

- **任何分类内都有便宜物种**——按属性、按进化链、按稀有度分档，都只是把套利窗口缩小，不能根除。
- 彻底的解法是绑到具体物种，但那样就失去了"救济稀有物种"的功能。
- **通用性 = 能救济稀有物种，也 = 能被廉价物种套利。** 这是个结构取舍，不是分类精度问题。

### 16.3 外部参考（成熟游戏怎么做）

| 模式 | 代表 | 做法 |
|---|---|---|
| 币按谱系绑定 | Pokémon GO 糖果 | 只给该进化链，烈雀糖换不到超梦 |
| 进度按物种累计 | Palworld 捕获数 | 同种抓够 N 只 → 该物种永久加成 |
| 通用币分层 | Factorio 科技包 | 红/绿/蓝/紫/黄瓶，高级科技只吃高级瓶 |
| 通用币分科 | Stellaris | 物理/社会/工程三池，永不互通 |
| 没有币只有配方 | Subnautica 碎片 / 怪物猎人素材 | 每个蓝图只认自己的碎片/素材 |
| 通用币只给折扣 | 文明 6 尤里卡 | 只打折，不免除 |
| 通用币 + 硬门槛 | XCOM 尸体 | 再有钱也得先拿到那份尸体 |

**共同点**：没有一款成熟游戏给"一种样本全免别的物种研究"；业界靠"不给通用性"或"只给折扣"解决。

### 16.4 克隆：用样本“定制”个体（讨论中，2026-11-20 方向已定）

> 设定：这不是宝可梦，是**火箭队造出来的东西**——制式产品，没有父母，也没有名字。

| # | 决定 | 内容 |
|---|---|---|
| 16-3 | ✅ **样本按物种绑定** | 烈雀样本只能造烈雀；不跨物种、不做通用研究进度 |
| 16-4 | ✅ **定制程度决定花费** | 定制项越多，样本花费越高（幂级） |
| 16-5 | ✅ **克隆体不孕不育** | 硬锁：不能进繁育。定位为道具，不是活体资产 |
| 16-6 | ✅ **克隆体体质 0.85** | 比正常低，但不是残废 |
| 16-7 | ✅ **能交单** | 可以交付部门订单（因此定制“性格”有实际价值） |

#### 规格草案

| 项 | 建议 |
|---|---|
| 个体值 | **固定中庸**（各项 15）——制式产品都是标品 |
| 来源标记 | 「制式」；来源文案写成编号式（“从 6 份烈雀样本里长出来的”） |
| 初始等级 | Lv.1（需要自己养到订单要求的等级） |
| 出售 | 可卖，但价格低——它值钱的地方是“符合需求”，不是“品相” |

| 定制程度 | 样本花费 |
|---|---|
| 纯复制（不定制） | 4 |
| 定 1 项（特性 / 性格 / 性别） | 8 |
| 定 2 项 | 16 |
| 定 3 项 | 32 |

#### 一条硬约束：不能变成印钞机

**“榨一只 → 造一只”必须亏本或刚好打平。**

按 `终末榨取 μ = 耐受 / 50`（Lv.60 约 4 份样本）算：纯复制花 4 份 = 刚好一只换一只；定制一项要 8 份 = 两只换一只。这样克隆的卖点是**省时间**（不用刷性格），不是**赚钱**。

如果样本产出高于克隆成本，就会出现“一只个体变多只商品”的无限循环，会盖过所有其他经济设计。

#### 待定

- [ ] 样本来源：目前只有「终末榨取」（要求该物种 100%）。是否让“实验致死”也给样本？
- [ ] 克隆体能不能出售（倾向可以，但价格低）
- [ ] 定制项最终保留哪几项（性别目前没有任何系统读取）

## 17. 渐进解锁（2026-11-20，✅ 方向已定，细节待定）

> **系统按“玩家的理解速度”解锁，而不是按“内容清单”一次性铺开。**

- 目的 1：避免开局就被一堆玩法淹没。
- 目的 2：贴合设定——你在火箭队里慢慢壮大、升职，才管得到更多事务。

### 17.1 两个天然载体（都已存在）

| 载体 | 是什么 | 已有实例 |
|---|---|---|
| **职级（权限）** | 组织允许你管更多事 | 6 级：声望 18/36/55/75/92，费用 1000/2800/6500/14000/26000；设施升级已有 rankReq |
| **行为（知识）** | 你亲手做过，才懂得怎么用 | 蛋组（繁育成功才揭示）、特性/分类（组织采样存活）、研究 100%（显示 IV） |

所以这不是新系统，是**把已有的门槛当成解锁系统来用**。

### 17.2 混合模型（✅ 2026-11-20 已定）

> **职级给「权限」，行为给「知识」。**

| 轴 | 含义 | 承担什么 |
|---|---|---|
| **职级（权限）** | 组织允许你接触什么——资源是组织给的 | 实验室（实验台是升职奖励）、设施升级、蛋贩子/商店渠道、传说任务 |
| **行为 / 研究（知识）** | 你亲手做到过，才真正掌握 | 蛋组（繁育成功）、特性/分类（组织采样存活）、IV（研究 100%）、终末榨取、**克隆** |

### 17.3 克隆的解锁：走知识轴

- **第一个物种研究到 100% → 解锁「克隆」技术**
- 之后只能克隆**已研究完**的物种——样本本身也只有这条路能拿到
- 设定：克隆是火箭队的机密技术，但**掌握它的是知识，不是职级**

### 17.4 声望问题：渐进解锁最薄弱的一环

现状：**声望只有一个来源（交付订单，+4 / +13）**，而职级是解锁的主轴之一。于是：

- 想升职级 → 只能刷订单
- 研究做得再深，对职级零贡献
- 两条进度线互不相通（§12.3 的 P0）

**建议：研究完成一个物种，给少量声望（如 +2）。**

- 让“职级”和“研究”两条线自然同步：研究快的人，职级也跟着涨
- 同时修掉 P0「研究是纯消耗」
- 需要重算节奏：92 声望 = 23 单，或 46 个研究完成的物种

### 17.5 草案（未定稿）

| 阶段 | 新解锁 | 轴 |
|---|---|---|
| **开局** | 培育栏、孵化、围栏、出售、**部门订单**、蛋贩子、研究笔记（只看得到 151 的目标） | — |
| 职级 1 · 助理研究员 | 进化（石头 / 电缆）、设施升级 | 权限 |
| 职级 2 · 研究员 | **实验室**（研究进度、能力值披露） | 权限 |
| **第一个物种研究到 100%** | **终末榨取**（可以处置该物种的个体） | 知识 |
| **第一次榨出样本** | **克隆（制式生产）** | 知识 |
| 职级 3–5 | 设施上限（已有 rankReq）+ 传说任务（未设计）+ 终局 | 权限 |

克隆因此走的是“行为链”：研究 100% → 会榨 → 有样本 → 会克隆。三件事都是**你做过才知道能做什么**。

### 17.6 三个要小心的地方

1. **早期会变薄**：解锁前，玩家手上只有繁育 + 卖 + 交单。前 10–15 分钟必须有足够的事做，否则不是“不晕”，是“无聊”。
2. **解锁时刻要有仪式**：不能只是导航栏多一个图标。至少是一张卡片 + 一条日志，说明“组织现在允许你……”。
3. **会挤压目标时长**：实验室若在职级 2（约 25 分钟）解锁，研究线就只剩 8.5 小时——要和 9 小时的预算重新对齐。
