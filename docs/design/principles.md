## 14. 界面信息原则（2026-11-20，✅ 已定）

> **信息跟着决策走：数据全量保留，界面只给"此刻要做决定时用得上的那几项"。**

### 14.1 三层

| 层 | 存/放什么 | 界面怎么用 |
|---|---|---|
| **数据层** | 全部保留（IV、蛋组、血统、耐受、来源……），逻辑随时可读 | 不管 |
| **决策点** | 做选择的那一刻，把相关字段推到眼前 | 选择器、对比、排序 |
| **默认视图** | 只留"不看就会做错"的少数几项 | 卡片 |

### 14.2 判定标准

**玩家此刻能不能基于它做出不同的选择？不能，就不显示。**

同一个字段在不同场景地位不同：蛋组在"选谁放进栏位"时是必需品，放进去之后就是噪音。

### 14.3 已应用

| 场景 | 决定 |
|---|---|
| 繁育栏卡片 | 删属性徽章、经验条；蛋组移到"选择放谁"的选择器；编号弱化 |
| 耐受度 | **已有灰度展示**，足以表达"母体还能不能撑"，不再加数字 |
| 个体详情（研究 100% 后） | **直接给出六项 IV 的具体数值** |

### 14.4 推论

- 隐性设定保护的是**没研究过的东西**；一旦研究完，具体数值可以直接给。
- **界面克制 ≠ 隐藏信息**：信息应当可获得，只是不必随时铺开铺满。
- 新加任何字段时先问：它属于数据层、决策点，还是默认视图？默认先放数据层，别默认放卡片。

### 14.5 复杂度原则（2026-11-20，✅ 已定）

> **逻辑可以复杂，操作必须简单。复杂度放进系统里，不放到玩家手上。**

| 层 | 可以有多复杂 | 玩家接触到的 |
|---|---|---|
| 血缘 | 祖先表、共同祖先、代数、体质系数、杂交优势 | 只看到「近亲」两个字 |
| 体质 | 0.85 衰减、杂种优势、封顶 | 只看到耐受灰度更短 |
| 遗传 | 六项均值 ±5、性格 50/50、死胎概率 | 只看到孵出来的结果 |
| 判定 | 任意深 | 只在需要时给结果 |

**推论**：

- 任何新机制都必须回答一句：**玩家会因此多做几个动作？** 如果是“每次都要多做一步”，就砍掉或改成自动。
- 玩家永远不需要查谱系、算系数、记代数。**如果他必须查表才能玩对，就是设计失败。**
- 已经通过“选哪两只”表达了的意图，不再额外加一个下拉。

### 14.6 由此砍掉的两项

| 项 | 处理 |
|---|---|
| 近亲标记分级（亲子/兄妹 vs 祖孙/表亲） | ❌ **不做**，只给一个「近亲」标记——分级会逼玩家按远近做不同决策 |
| 配种意图（像父 / 像母 / 求稳） | ❌ **不做**——“想要什么”已经通过“选谁做亲本”表达了，再加下拉是每次配种多一步 |

### 14.7 文案规则（2026-11-20）

> **界面文字只写「它是什么 / 它做了什么」，不写「为什么」和「你该怎么做」。**

这条是对 §14 的补充，针对一个反复出现的坏习惯：每加一个机制，就顺手加一句解释。

**禁用**：

- 「要……才……」「先……再……」「注意」「建议」「⚠」
- 对机制的自我解释（"耐受越高，留下的东西越多"）
- 教学句（"要判断这只好不好，先把这个物种研究完"）

**允许**：

- 名词标签：繁殖 / 耐受 / 编号 / 未知
- 状态词：已完成 / 已确认不合 / 未编号
- 结果句：发生了什么
- 世界观文案：实验描述、处置正文（这些是内容，不是说明）

**判定方法**：删掉这句，玩家会不会**误判发生了什么**？会，保留；只是告诉他“该怎么想、该怎么做”，删。

**已删的实例**：

| 原文 | 位置 |
|---|---|
| 「⚠ 样本会被用尽 · 耐受越高，留下的东西越多」 | 终末榨取卡 |
| 「要判断这只好不好，先把这个物种研究完」 | 个体详情（体格方案，已砍） |

## 15. 设定基调（2026-11-20，✅ 已定）

| # | 决定 | 内容 |
|---|---|---|
| 15-1 | ✅ **玩家不是卧底** | 他是**自愿留下、清醒计算过代价的理性人**，不是被迫者，也不暗中反抗 |
| 15-2 | ✅ **他知道这是恶** | 但他判断这些研究成果能为世界带来更大的东西。他不辩解，也不忏悔 |
| 15-3 | ✅ **研究笔记不是罪证** | 那是正作里奠定人类认知的那本书。他用这座地下室和这些个体写成了它 |
| 15-4 | ✅ **不拟人、不煽情、不指责** | 宝可梦没有"抗拒""亲密"的表现。残忍来自**效率与冷漠**，不来自展演——写"它被拖出来"比写"它哀鸣着"更冷 |
| 15-5 | ✅ **游戏不评判玩家** | 只把代价摆在面前，不给道德提示 |

### 15.1 旧理解 vs 更正

| | 旧（错） | 新 |
|---|---|---|
| 身份 | 卧底、暗中反抗 | 自愿的合作者，清醒的共谋 |
| 动机 | 留证据、等时机 | 只有这里的样本与设备，才写得成那本书 |
| 情绪 | 隐瞒、不安 | 冷静、算过账、不解释 |
| 调子 | "组织不知道" | "我知道，我选择" |

### 15.2 需要同步修改的现有文案

现在的开场白与 README 还是旧理解：

> 「你是年轻的大木博士，被"请"进火箭队的地下基地：替他们管理与运营抢来的宝可梦，同时**偷偷记录**每一只的数据……」

"被请"与"偷偷"都与基调冲突。建议改成：

> 「你是年轻的大木博士。你自愿留在这座地下基地——外面的世界不会给你这些样本，也不会给你这些设备。代价你清楚，你付得起。」

### 15.3 残忍该放在哪里

**不放在形容词里，放在数字里。** 现有的"母体 100 耐受、每胎 −32、三胎力竭而死"本身就是最狠的一句，不需要再加任何形容。
