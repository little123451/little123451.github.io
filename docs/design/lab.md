## 11. 实验室与研究（讨论中）

### 11.1 现状数字与痛点

- 研究需求 = `40 + (255 − 捕获率) × 1.4`：烈雀 40、皮卡丘 131、化石翼龙 334、超梦 393
- 一轮实验（5–8 条各做一次）约给 30–40 点进度 → 稀有物种约需 10 轮、**60–80 次点击**
- harsh 档一次损耗约 110 点耐受 → Lv.1 个体一击即死
- 物种研究 100% 后：只剩最伤身那条实验，不再记日志，实验室对该物种基本失去意义

三个结构性问题：

1. **决策不可见**：成本只标资金，耐受损耗与进度收益都隐藏，玩家只能凭经验记，谈不上权衡
2. **产出单一且一次性**：只产出"研究进度"，100% 后变成真空
3. **物种同质**：458 条专属实验只是文案不同，机制都是三档，151 次体验高度重复

### 11.2 新方向：满研究后转为"献祭式产出"

讨论确定的方向（**先只做产出端，消费端以后再说**）：

| 项目 | 决定 |
|---|---|
| **动作名称** | **「终末榨取」**（四个字；文案里不再出现"实验"） |
| **可用动作** | 研究 100% 后，只保留 **1 条终末榨取**（原计划 5 条极端实验，为避免铺开缩减） |
| **样本结局** | 这条动作**一次就耗死样本**（必死，不留活口） |
| **产物数量** | 由样本的**当前耐受度**决定，再叠加随机影响（正态分布） |
| **产物种类** | 先只做 **1 种产物**（不做 5 种） |
| **消费端** | 暂不设计（后续再定：加速研究 / 研究部订单 / 其他） |

### 11.3 产物公式草案（正态分布）

讨论确定：**产物数量用正态分布**——大多数情况落在平均数附近，少数情况会明显偏多（或偏少）。

参数建议：

```
μ = max(1, 当前耐受 / 50)       // 平均产出，随耐受提升（2026-11-20 由 /35 改为 /50，对齐克隆成本）
σ = max(0.6, μ × 0.3)           // 波动幅度
数量 = clamp(round(正态(μ, σ)), 1, 上限)
```

概率表现（σ = 0.3μ）：

| 样本耐受 | μ | 常见区间（±1σ） | 偶尔偏多（≥μ+2σ） | 极罕见（≥μ+3σ） |
|---|---|---|---|---|
| 100 | 2.0 | 1–3 | 3–4 | 5 |
| 158 | 3.2 | 2–4 | 5–6 | 7 |
| 218 | 4.4 | 3–6 | 7–8 | 9+ |
| 273 | 5.5 | 4–7 | 9 | 11 |

**为什么是 /50**：纯复制一只克隆体要 4 份样本。用 /35 时 Lv.60 能榨 6 份，等于“榨一只造一只半”，会变成印钞机；用 /50 时约 4.4 份，正好一只换一只。

实现说明：游戏用的是种子化 LCG，取两次 `random()` 做 Box–Muller（或四次均匀数叠加近似正态）即可，
仍然是可复现的确定性随机。

设计要点：

- 用**当前剩余耐受**而不是上限：先拿去繁育/实验过的个体，献祭时产物更少 → "留着献祭还是先用"成为取舍
- **正态的尾巴是对称的**：偶尔也会明显偏少。**已决定：暂不保底**，先按完整正态跑，后续按游玩体验再调整
- 上限要设，否则极端值会失控（建议 ≤ 2μ，待定）

### 11.4 命名、文案与呈现（已决定）

| 项目 | 决定 |
|---|---|
| 动作名 | **终末榨取** |
| 为什么改名 | 100% 之后的行为不是"实验"而是"处置"；沿用原实验名会让玩家用旧经验误读（同一名字，之前可反复做、可能活下来，之后却一次必死） |
| 文案方向 | **解剖 / 肢解**——样本是"取"出来的，不是"实验致死"，产物来源才合理 |
| 采用的呈现结构 | **结构二**：正文只写处置，原实验名退为一行"此前完成的是「XXX」" |
| 为什么不用结构一 | 结构一是"引用原做法 + 解剖收尾"，遇到温和的原描述（如波波的"应激阈值"）仍会违和 |
| 结果卡 | 标题 `处置完成 · 样本已耗尽`，不使用"实验结束" |
| 进度 | **不显示研究进度**，只显示费用与提示 |
| 死亡与遗体 | 沿用现有规则：留遗体占用实验台，6 资金处理 |

**界面示例（结构二）**：

```
┌──────────────────────────────────────────────┐
│ 终末榨取                           🪙 180     │
│ 此前完成的是「应激阈值」                        │
│ 不再记录反应，也不再抢救：从旧伤口下刀，把还能用的部分逐件取下。│
└──────────────────────────────────────────────┘
```

> 2026-11-20 修正：删掉了原稿里的「⚠ 样本会被用尽 · 耐受越高，留下的东西越多」。
> 这类“解释机制/提示玩家”的文字与本作风格冲突——界面只写**发生了什么**，不写**为什么**和**你该怎么做**（见 §14.7）。

**文案清单（共 5 段，不需要 151 段）**：

| 类别 | 数量 | 说明 |
|---|---|---|
| 通用处置正文 | 1 段 | 所有物种共用 |
| 特殊物种专用 | 4 段 | 波波 / 比比鸟 / 拉达 / 皮皮（最伤身实验只有 standard 的那 4 只） |

**已写好的 4 段专用文案（结构二下）**：

| 物种 | 专用描述 |
|---|---|
| 波波 | 不再挑衅。把它按在台上，先取翼膜，再按清单分割。 |
| 比比鸟 | 飞行数据已经够了。翅膀被整片取下——飞行肌是这批样本里最值钱的部分。 |
| 拉达 | 不再放回水槽。从腹部下刀，取出还温着的内脏。 |
| 皮皮 | 不再观察。把它从藏身处拖出来，按部位分装。 |

**备选（暂缓）：按体型/类别分 5–6 个变体**，解决"同一段文字出现 151 次"的重复感：

| 类别 | 文案示例（克制版） |
|---|---|
| 小型 / 普通 | 一只手就能按住。下刀，取出能用的部分，剩下的算损耗。 |
| 鸟类 | 翅膀先卸下来，飞行肌整片取下；剩下的按清单分割。 |
| 水生 | 放干水槽，从鳃部下刀，腹腔里的东西一件件装进容器。 |
| 岩石 / 矿物 | 先砸开外壳，再按硬度分拣内层——能取的东西比预想的多。 |
| 幽灵 / 气体 | 气体被抽进容器，剩下的残渣用刮刀收起来。 |
| 大型 / 重型 | 需要两个人按住。分批切割，能用的部位一件件运走。 |

决定：**先按 5 段上线**，玩过之后如果觉得重复，再加 6 组分类变体（结构不变，只是把通用段换成"按类别取值"）。

### 11.6 实验流程改造（已决定）

| 项目 | 决定 | 理由 |
|---|---|---|
| **实验条数** | **保留 5–8 条** | 重复执行已经秒结算，多点几下成本低；458 条专属实验的内容不浪费 |
| **实验冷却** | **保留**（5–28 秒真实时间，按个体+实验） | 它防的是"连续点同一格"，也是现在唯一的节奏来源 |
| **递减收益** | **不做** | 实验室的选择被定义为**效率题**：harsh 永远最优，这是设计而不是缺陷 |
| **"各做一次才能到 100%"** | 保留（现有 `未做数 × 2%` 上限） | 唯一还保证其他实验被看到一次的东西 |
| **重复执行的加载条** | 删除（只在首次保留） | 减少每次点击的摩擦 |
| **重复执行的结果卡** | 删除，只写一条日志 | 玩家第三轮之后不会读；文案留在日志里可回看 |
| **实验日志逻辑** | **不改**：每次实验（含重复）照常写入研究笔记的实验日志 | 实验体很少能熬过 10 次实验；玩家倾向最高档时，1–2 次就会把一只用死，日志量不会失控 |
| **首次执行** | 保留加载条 + 完整结果卡 | 仪式感与物种风味集中在这里 |
| **死亡 / 研究完成** | 总是弹卡 + 日志高亮 | 重要事件必须被看见 |

#### 为什么保留冷却（讨论记录）

原本冷却的作用是"防止玩家只做压力最大的实验"。但按现值算，**资源效率最高的其实是 gentle**，
harsh 的优势只是"每次点击给得多"；而个体过剩时，玩家不在乎消耗，所以效率最优就是 harsh。
这个"玩家总选最高档"的现象无法用递减收益纠正（递减只会让玩家改成两个按钮轮流点），
因此决定：**接受效率题的本质，把冷却保留下来作为节奏控制，其余摩擦全部去掉**。

### 11.8 实验分工（🕒 2026-11-20 决定：维持现状）

讨论过让「体测」承担能力值披露（一次全开 / 六次逐项），最后**决定不改**：

| 项 | 结论 |
|---|---|
| 组织采样 | ✅ 唯一有专属角色的实验：首次存活 → 解锁该物种的特性 / 分类 |
| 基础体测 / 对战测试 / 专属实验 | **纯进度**，不承担信息产出 |
| 能力值六项 | **继续按研究进度逐项披露**（每约 16.7% 一项），不由实验行为解锁 |

理由：能力值跟着“研究多深”走，是这个游戏已有的叙事——研究得越深，越看得懂它；把它挪到“量一次就全知道”，会削弱这条线，也丢掉逐项披露的节奏感。

**代价**：实验室少了一个“先侦察还是先深挖”的分岔。面对新物种时，玩家的决策只剩三个——用哪只个体、先做哪条实验、什么时候交给助手。

## 18. 实验室助手（2026-11-20，✅ 已定）

> 把“点击器”改成“投放”：玩家亲手做发现，助手做重复。

| # | 决定 | 内容 |
|---|---|---|
| 18-1 | ✅ **独立解锁** | 「实验室助手」是一个解锁项（草案：职级 3 · 高级研究员） |
| 18-2 | ✅ **自动的前提：先把该物种亲手做完** | 一个物种的 **5 条实验全部亲手做过**，才算“亲自处理过”；在此之前助手不会碰这个物种 |
| 18-3 | ✅ **连续 tick，不是离散点击** | 耐受按秒下降、进度按秒上升、耗材按秒扣钱；UI 显示「助手研究中」 |
| 18-4 | ✅ **暂时只有 1 个助手** | 一个助手只负责一个实验体；后期可升级为多个 |
| 18-5 | ✅ **打断 = 玩家接管** | 打断后助手让位、在旁边观摩（仍占用）；玩家可以亲手做这个物种的任意实验，也可以随时把自动交还给助手 |
| 18-6 | ✅ **到 100% 自动停，但仍占用** | 研究完成不等于收工——要等玩家处置这只个体，助手才释放 |
| 18-7 | ✅ **实验体必死** | 入台即判死。实验室没有出口，只有死亡或“处理”（现状本来如此） |

### 18.1 数字（对齐 harsh 档）

| 资源 | 速率 |
|---|---|
| 研究进度 | **0.5 点/秒** |
| 耐受损耗 | **3.86 点/秒** |
| 实验耗材 | **6.4 金/秒**（12.9 金/进度点） |

一个助手 ≈ 0.5 进度/秒；全图鉴 37,499 点 = **20.8 小时**。所以单个助手是“第 5 台免费实验台”，**是补充不是替代**；玩家同时手动跑 4 台时总吞吐约 2.5 点/秒，全图鉴 4.2 小时，落在 8–10 小时框架内。

### 18.2 设定补丁：助手是「实验台负责人」

“100% 后仍占用助手”在机制上成立，但需要一个说得通的理由：

> **助手不是研究机器，他是这个实验台的负责人。** 从入台到清场都归他管：做实验、写记录、清理台面。**台子不空，他不能走。**

这样三件事一次解释：

- **为什么占用**：他负责的不是“跑进度”，是这台子的全流程
- **为什么打断后还在**：你在做实验，他在旁边学
- **为什么清场才释放**：他要收尾

### 18.3 附带改名

实验“费用”在设定上改成 **实验耗材费**（试剂、容器、电）——这也解释了为什么助手是组织派的、不领工资，但你依然要花钱。

### 18.4 一次完整流程

```
新物种（未亲手做过）→ 放进实验室 → 助手不接手，只能玩家自己点
        → 玩家亲手做完这 5 条实验（助手在旁边观摩）
        → 该物种标记为「已亲自处理」
        → 之后再放入该物种的个体 → 助手开始自动研究（耗材费照扣）
        → 自动刷到 100%
        → 助手停下但仍占用
        → 玩家点「终末榨取」（按钮就在那只个体下面）
        → 个体死，产出样本（μ = 当前耐受 / 50）
        → 遗体占位 · 按现有规则花 6 金处理（不自动清场）
        → 台子空 → 助手释放，接下一个物种
```

**终末榨取的四条定案（2026-11-20）**：

| # | 项 | 决定 |
|---|---|---|
| 1 | 产物公式 | `μ = 耐受 / 50`（对齐克隆成本，一只换一只） |
| 2 | 榨完是否自动清场 | ❌ **不自动**：遗体照旧占位、花 6 金处理，然后助手才释放 |
| 3 | 按钮位置 | 就摆在那只个体下面 |
| 4 | 是否显示预计样本数 / 说明文字 | ❌ 都不显示（见 §14.7 文案规则） |

**分工**：手动 = 第一次探索（钥匙），自动 = 收尾与复制（引擎）。助手永远不能替你做“第一次”。

### 18.5 打断的定位（2026-11-20）

打断不是为了“救”，也不是为了效率——它没有任何数值优势。

> **打断 = 把它给我，我亲自来。**

- 玩家接管这个实验体，助手在旁边观摩（仍被占用）
- 可以随时把自动交还给助手
- 唯一的不同：**手动有反馈，自动只有日志**——你亲手做的每一次实验，都会看到它的反应

这条机制不为收益服务，它服务于角色：玩家的默认行为不是善。游戏不评价这件事，只是允许它发生。

### 18.6 日志与记录：自动研究怎么写

自动研究是**连续 tick**，没有离散的“第几次实验”，所以它没法像手动那样逐条落笔。

**沿用现有的日志结构**：按个体编号分组，组内按天。助手相关的记录用三条固定文案：

| 事件 | 文案 |
|---|---|
| 助手接手 | **「安排助手对其进行实验」** |
| 玩家打断、接管 | **「你决定亲自动手」** |
| 个体死亡 | 沿用 **「实验结束后对象死亡」** |

样例：

```
#0042  烈雀  Lv.58
  D12   安排助手对其进行实验
  D14   你决定亲自动手
  D14   用钳子从活体上硬扯下一块皮肉，伤口不缝合，观察它疼到抽搐。
                                                    [实验结束后对象死亡]

#0051  烈雀  Lv.55
  D15   安排助手对其进行实验
  D17   实验结束后对象死亡
```

- 组头**去掉「N 次」**，只留 编号 / 物种 / 等级
- 助手阶段不逐条记录，只有「接手 →（可选）打断 → 死亡」三类节点
- 助手阶段的死亡不配动作文案，只有那一行标记
- **研究到 100% 不额外记日志**：维持现有“研究满后不再写日志”的规则，完成与否由图鉴格子体现
- 手动做的实验仍逐条落在它自己那一组里

#### 图鉴里只给总数，不拆账

图鉴条目**不显示**「亲手几条 / 助手几只」这种拆分，沿用现有的两项总计：

- **损耗 N**（被研究消耗掉的个体总数，助手用掉的也算在内）
- **研究成本**（耗材 + 遗体处理）

数据层可以分开记录（`assisted` / `assistantLost`），但**界面不展示**——按 §14 的原则，它不改变玩家此刻的任何决定。

### 18.7 节奏定案（✅ 2026-11-20，按建议直接定，后续按体验调）

| 项 | 决定 | 理由 |
|---|---|---|
| **助手解锁** | **职级 3 · 高级研究员** | 实验室在职级 2 开；先让玩家手动做几个物种，等“手动开始变重”的时候助手正好到 |
| **第 2 个助手** | **职级 4 · 首席研究员** | 与“升职 → 管更多事”的设定同构 |
| **第 3 个助手** | **职级 5 · 干部** | 同上，封顶 |
| **打断后能否做“非首次”实验** | **可以** | 打断就是接管，玩家想做什么做什么 |
| 自动研究的其它限制 | 无（只有“未做实验压 2%”这一条） | — |

**为什么助手数量不必急着给满**：助手只是“后台那一路”，玩家自己的 2–4 台实验台始终在跑。助手多一个，等于少点很多次；但即使只有 1 个，游戏也能玩——只是慢。所以数量按职级给，是节奏调节，不是硬需求。
