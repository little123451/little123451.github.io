# 火箭队模拟器 · 第一世代

> 你被“请”进火箭队的地下基地，替他们管理与运营抢来的宝可梦。
> 表面上，你是个听话的年轻研究员；暗地里，你在为那部尚未问世的“宝可梦研究笔记”积累第一手资料。

基于 [PokeAPI](https://pokeapi.co/) 第一世代（#001-#151）数据的静态经营游戏：配种、孵化、养成、满足火箭队各部门的需求、扩建设施。纯前端、零依赖、无后端，可直接部署到 GitHub Pages。

## 游戏设定

**时间线**：大木博士还年轻，研究笔记尚不存在，宝可梦研究刚刚起步。

**处境**：你在一次野外考察中被火箭队盯上。他们没有为难你——他们需要一位懂宝可梦的人，来管理基地里越堆越多的“战利品”。作为交换，你获得了自由出入培育区的权限，以及一间勉强能用的实验室。

**日常**：为抢来的宝可梦配对、孵化、养大，按各部门的需求交付。基地的运转离不开你，而你也离不开基地——至少在你写完那本笔记之前。

**暗面**：实验室才是你真正的目的地。表面上，你替火箭队管理培育栏、孵化器和实验台；实际上，每一场实验都是在替那部还不存在的研究笔记补数据。实验对象的耐受度归零时，它们会被当作“损耗”消亡——你把结论写进笔记，把尸体留在基地。

**职级**：你从**见习研究员**做起。声望达标后花资金晋升，职级越高，能申请到的设施等级越高。

**部门**（订单来源，游戏内随机出现）：

| 部门 | 需求偏好 |
| --- | --- |
| 后勤部 | 什么都收，数量优先，等级要求低 |
| 研究部 | 博士自己的实验样品，偏爱稀有物种与特殊性格 |
| 警卫队 | 能打能扛，等级要求高 |
| 通讯部 | 电系宝可梦，用于干扰与窃听 |
| 走私组 | 稀有货，越难搞越值钱 |
| 外勤组 | 野外行动需要可靠的伙伴，属性对口优先 |
| 总裁办 | 总裁亲自过问的事：要求高、给得多、框体特殊；随职级提升才会渐渐多起来 |

**走到这里**：完成第一世代 151 个物种的研究进度；**或**把职级升到最高（干部）。这不是传统意义的战胜或击败，只是游戏在某条路上承认你的努力，到这里就可以收束本局；之后仍可继续经营。

> 设定以本文档为准。游戏中已体现部门归属、订单类型、实验室、职级与收束条件；剧情对话、部门好感度、研究笔记文本等仅作背景设定，未全部实现。
> 已知缺口：传说 / 幻兽（#144~#146、#150、#151）目前没有获取渠道，等后续补充走私拍卖等设定；这不影响职级收束条件。

## 待实现设定

- **正义之士营救**：偶尔会有正义之士摸进基地营救宝可梦，造成一定的损失——声望、资金、宝可梦与蛋都可能被带走。目前只作为背景设定，**尚未实装**（玩法说明里的“传闻”指的就是这条）。
- **实验结果文案暂时停用**：当前版本不再展示实验行为的结果文案，也不再加载 `data/results/`；相关结果池与 `js/results.mjs` 保留，等待后续重新启用。实验只保留生还/死亡状态、耐受度、进度和日志记录，结果卡与研究笔记日志都不再显示结果文本。

## 玩法

1. **繁育**：栏位里放两只就会积累繁育条（不看你放的是谁）。条满时按内部条件判定：
   - 条件成立（一雄一雌、蛋组有交叠、没有未发现蛋组）→ 产蛋，**母体会掉 32 点耐受度**——低等级的母体大约繁育 3 只后代就会耗尽，等级越高耐受上限越高、越耐用；**百变怪参与且没有雌性时（百变怪 + 雄性/无性别），损耗落在百变怪身上**，雄性不掉耐受度。雄性不再有繁育次数上限。
   - 条件不成立 → 两只争斗，**较弱的一只阵亡**（先比等级，同等级比种族值），另一只掉 28 点耐受度。只有**同性、蛋组不匹配**这两类会真的打起来，争斗文案会点明是哪一种。
   - **两只百变怪**、**未发现蛋组的物种**（传说 / 幻兽）根本放不进同一栏；**无性别**的宝可梦（小磁怪、海星星、多边兽…）放进栏位不会和任何配对打起来，只是静默地配不上、不产蛋。
   - 繁育条满但孵化器没空位时只会等待，不会受伤（条停在 100% 并提示「孵化器已满」）。
   - 培育栏里死亡（争斗或力竭）会留下**遗体**占住那个位置，花 **6 资金**处理才能放新的。
2. **蛋组未知**：博士一开始完全不知道任何宝可梦的蛋组，界面上只显示 `？？？`。只有亲手繁育出蛋，才会确认两边交汇的那个蛋组；同一个物种的另一个蛋组要等它和别的蛋组也繁育成功才会公开。
3. **孵化**：蛋在孵化器中倒计时，孵出的永远是家族**最初形态**（猫老大的蛋孵出喵喵）；孵化步数（`hatch_counter`）越高越慢，孵化器每级加速 10% 并 +1 蛋位。**孵出后默认进入围栏**，不会再自动塞进培育栏。
4. **养成**：栏位中的宝可梦持续获得经验（训练场可加速），喂**经验糖果**可快速加经验。
5. **进化**：升级自动进化；石之进化、通信进化需在详情页手动触发并消耗道具。
   - 通信进化（勇基拉 / 豪力 / 隆隆石 / 鬼斯通）需要「通信电缆」。
   - 伊布、皮卡丘、六尾、卡蒂狗等需要对应进化石。
6. **实验室（研究笔记唯一解锁途径）**：把宝可梦放进实验台，消耗资金进行实验，累积该**物种**的研究进度。
   - **没有免费的实验**：基础体测 15 资金起，越深入越贵；所有实验的资金消耗统一按 `experimentCostMultiplier = 1.5` 放大。
   - **实验分两类**：三条基础实验（基础体测 / 组织采样 / 对战测试）+ 该物种的专属实验。专属实验按研究笔记描述编写，每只 2–8 条；不足 5 条时按强度从高到低补入基础三条（对战 → 采样 → 体测），补到 5 条；5 条以上不再补。最终 5–8 条，按强度升序排列。
   - **专属实验只有三个档位**：`gentle`（进度 3 / 资金 30 / 冷却 6 秒 / 损耗最低）、`standard`（7 / 83 / 14 秒）、`harsh`（14 / 180 / 28 秒 / 损耗最高）；基础三条分别为 2 / 15 / 5 秒、4 / 45 / 10 秒、8 / 90 / 16 秒。数值集中在 `js/rules.mjs` 的 `EXPERIMENT_TIERS` 与 `CONFIG.experimentCostMultiplier`，内容在 `data/experiments.json`。
   - **研究进度已整体下调**（约为早期版本的一半），**每次实验的耐受度损耗约为早期的十二倍**（除数 12 → 1）——普通个体打一场 harsh 实验基本就是最后一场，连基础体测都要掂量。
   - **冷却按“个体 + 实验”独立**（按真实秒计）；同一只个体做过的实验才进入冷却，换一只个体不共享冷却。**该物种研究 100% 后冷却取消。**
   - **实验过程**：选择行为后先显示“正在 XXX”的短加载条（基础约 0.9 秒、标准约 1.4 秒、harsh 约 2 秒），加载界面展示该行为的描述与纯视觉进度条（不显示百分比数字）；生还时直接回到页面，只有死亡时才弹出仅含个体编号与遗体处理信息的结束卡，不展示结果文案。**选择界面只显示行为名称、费用和冷却，不展示描述。**已执行过的行为会显示“已记录”样式。
   - **结果文案池**：每条实验行为仍有独立的 50 条结果库存，但当前版本**不加载、不展示、不写入新日志**；`data/results/` 与 `js/results.mjs` 保留，方便后续重新启用。
   - **实验日志**：每次实验仍会写入日志数据，但日志只显示行为描述与生还/死亡状态，不显示结果文案。物种详情显示该物种最近 10 条；研究笔记总页不再展示全局日志。实验栏里**手动处理活体**也会写入日志并计入研究损耗。**该物种研究 100% 之后不再记录任何实验日志**（包括之后的实验、死亡与处理）；研究完成的那一条日志会保留并高亮。**死亡后处理遗体不再重复写日志/计损耗**，因为死亡发生时已经记录过一次。
   - **死亡结果卡**：可点「处理遗体」付费空出实验台，或直接关闭；资金不足时不会强制卡住。
   - **放进去就取不出来了**，只能继续实验，或花金币**处理**；活体处理费约 `8 + 剩余耐受度 × 12%`，耐受度越高越贵；遗体固定 6 资金。
   - **实验室死亡会留下遗体并占用实验台**，必须花少量金币处理遗体，才能放入新的实验对象。
   - 实验超载、耐受度耗尽、争斗失败、被实验惊吓等死亡文案会按场景写成断气、力竭、伤重不治等。
   - 实验会按隐藏的攻击 / 特攻参数扣除耐受度。
   - **实验窗口不显示进度与预计损耗，只标资金消耗**——具体影响要自己记录。
   - 耐受度归零：结算完本次进度后死亡并留下遗体；若是「下一次实验会扣到负数」，则实验不生效（不给进度、不扣资金），直接死亡并留下遗体。
   - 研究要求按稀有度（`capture_rate`）决定，越稀有越难：波波 40、梦幻 334。
   - **物种研究完成后**，这只宝可梦只剩“最伤身”的那一种实验（该物种损耗最大的实验，通常是 harsh 档）还能记录到新数据，其余行为不可用。
   - **实验室挣扎**：耐受度高于 70 的个体会在实验台上缓慢消耗耐受度（每天 2 点），降到 70 停止。
   - **高损耗实验的威胁**：harsh 档（或损耗达到自身耐受上限 50% 以上）的实验，会让同实验室的其他个体“挣扎”，按各自耐受上限的 6% 扣耐受度；耐受度不足上限 10% 的个体不受影响。
7. **耐受度**：耐受度上限**和等级、性别挂钩**（Lv.1 雌性 100，每升一级 +2，Lv.60 雌性 218；**雄性在同等级基础上 ×1.25**，Lv.1 雄性 125、Lv.60 雄性 273），出厂即满值，升级时同步补上这一级的差值；但**只有进了实验室才会在界面上显示**。繁育、争斗、霸凌、实验都会消耗它；归零（或更低）时，实验室个体会死亡并留下遗体占位，围栏里被霸凌致死的个体会留下遗体等待处理，**培育栏里死亡的个体会留下遗体（处理费 6 资金）**，其他情况离队。
   - **闪光 / 不孕不育**：新个体出生时 **1/4096** 概率闪光，**2/4096** 概率获得不孕（雌性）或不育（雄性）。闪光仅视觉标记（金色光晕 + ✨），不影响数值；不孕/不育个体无法配种，但不会因此触发争斗。
8. **能力值披露**：刚接触的物种看不全能力值。随着该物种的研究进度推进，六项能力按**种族值从高到低**逐项披露（进度每约 16.7% 披露一项，100% 时全部公开）。个体值仍然参与计算，但不再展示。
9. **围栏**：不在培育栏、也不在实验室的宝可梦会待在**围栏**里；点卡片可以查看详情、喂糖果或出售。要放进培育栏，点培育栏空位的「放入宝可梦」——围栏卡片本身不再提供“放入栏位”快捷按钮。**已经在栏位里的个体**，在详情页可以：**「放入实验室」**（直接送进实验台，栏位随空出、繁育条归零）或**「扔回围栏」**。
   - **围栏用开关分两段**：顶部开关在**「培育相关」**与**「其它」**之间切换，一次只显示一段。培育相关 = 培育栏里出现的物种，以及这些物种**整条进化链**上的个体（例如栏里放了伊布，水伊布/雷伊布/火伊布都算）；其它 = 不在这条范围里的闲置个体。开关上带各自数量，原来按属性 / 性格筛选的功能已删除。
   - **遗体单独一栏**：围栏里被霸凌致死的个体会集中显示在底部的「遗体」栏（不受上面的开关影响），处理费 6 资金。
   - **围栏霸凌**：同物种、同性别的个体达到 **4 只**后，从第四个起，**最弱的那只**会被持续霸凌，只有它掉耐受度；2–3 只不会互相伤害。**百变怪不会被霸凌，也不会形成霸凌群体。** 被霸凌的个体会显示**红色边框与微弱呼吸动效**，移走一只（送培育栏/出售/交付）即可停止。霸凌致死的个体不会直接消失，而是留下**遗体**，需要花 **6 资金处理**；界面会在围栏顶部标出正在被霸凌的物种与数量。
   - **失败组合锁定**：只有 A、B 两个**异性物种因蛋组不匹配**导致配对失败时，才会永久记住该组合；之后 A 在培育栏中配对时，B 物种在伙伴选择列表中显示为**不可用**，但不额外说明原因。这个锁定**不会解除**。**同性争斗、力竭等其他失败不记录，也不锁定物种组合。** 已锁定的那一对留在栏里时，**只警告一次**，繁育条不再空转。
   - **驻守**：围栏页下方预留 4 个驻守位，用于之后对抗前来营救宝可梦的正义之士；当前仅占位，**暂未启用**。
10. **部门需求**：任意 / 属性 / 指定物种三类，按时交付得资金与声望。只能交付**围栏里闲置**的个体；实验室和培育栏里的宝可梦不会出现在交付列表。**未完成不再直接扣声望**：过期或主动回绝都不扣；但**距离上次完成需求超过 3 天后，声望会按天流失**，起始 0.5/天，闲置每多 1 天再快 0.1/天。过期只计入统计与内部记录，不会刷进界面日志。
    - **金币奖励**：普通部门整体下调（基础订单奖励 ×0.4）；总裁办大幅提高（×3.2）。
    - **总裁办**：出现概率极低（见习研究员约 2%，每升一级职级 +1.2%，干部也只有约 8%），要求更高、报酬远高于普通部门，框体有专属金色横幅、光泽与皇冠水印；交付 **+13 声望**，过期/回绝不再扣声望。
11. **经营与职级**：资金用于买蛋、经验糖果、进化石与设施。蛋由**蛋贩子**供货，**每两周（14 天）自动换一批货**；也可以花钱“换一批”，费用逐次递增，但会随天数回落。需求物种的蛋更容易出现（蛋只标**蛋组**与**来源**，不标属性与孵化时间）；来源是完整描述（共 **300 条**，如「从训练家后院抢来」「从走私船的货舱里截下」），会跟着蛋 → 个体走完整个生命周期。声望达标后花资金晋升职级：

    | 职级 | 声望 | 资金 |
    | --- | --- | --- |
    | 见习研究员 | 0 | — |
    | 助理研究员 | 18 | 1000 |
    | 研究员 | 36 | 2800 |
    | 高级研究员 | 55 | 6500 |
    | 首席研究员 | 75 | 14000 |
    | 干部 | 92 | 26000 |

    设施的每一级都有职级门槛（例如第 4 个培育栏要助理研究员、第 4 个实验台要高级研究员），没到职级时按钮会显示“需 ××”。设施包括培育栏、实验台、孵化器、广告牌、训练场（**自动喂食器已移除**——它只会堆经验不升级，与“喂糖是手动决策”的设定冲突）。
12. **研究笔记记录**：研究笔记 TAB 顶部汇总**实验总成本**与**累计损耗**，不再展示研究记录列表、实验成本明细或全局实验日志。每个完成的研究笔记条目仍记录完成日期与损耗数，可在物种详情查看。实验日志继续写入数据，但只显示行为与生还/死亡状态，不显示结果文案；让该物种研究达到 100% 的那条日志会高亮，并额外显示“对 XXX 的研究完成了”。**该物种研究满 100% 之后不再产生新的实验日志**。
    - 研究笔记格子分三态：**未研究**是黑色剪影与 `???`；**研究进度 > 0 但没满**显示灰度图标、物种名与进度；**100% 完成**才恢复彩色。
    - 研究过的格子可以点开**物种详情**：属性、蛋组、**种族值**、进度、损耗、**研究成本**（实验与处理的累计花费），以及该物种的**研究笔记描述**。种族值按研究进度逐项披露（与个体详情同一套逻辑），蛋组未确认时仍显示 `？？？`；**该物种研究 100% 后会补全蛋组信息**（即使没通过繁育确认）。描述是研究产出的条目，**完成 100% 研究后才会揭晓**——来源是官方《Let's Go 皮卡丘/伊布》的简体中文研究笔记文本（151 只全覆盖）。
13. **走到这里 / 认输**：**151 个物种的研究全部完成**，或**职级达到最高（干部）**时收束；这不是战胜或击败谁，只是游戏承认你在这条路上的努力。也可以随时点右上角菜单里的「离开火箭队」认输，本局立即结束（时间停止推进），结算面板里可以重新入职开新档；收束后仍可继续经营。

## 数据

- `tools/fetch-data.mjs` 从 PokeAPI 抓取并压缩生成 `data/dex.json`（约 123 KB）：
  中文名、属性、种族值、**特性（数据已抓取，游戏内暂不展示）**、蛋组、孵化步数、成长曲线、捕获率、性别比例、进化链、25 种性格，以及**研究笔记描述**。
- **手工数据修正**：PokeAPI 把**尼多娜 / 尼多后**标成「未发现蛋组」（第二世代起的设定），会导致尼多兰 Lv.16 自动进化后永久失去繁育能力，而雄性线不受影响。
  `js/data.mjs` 的 `EGG_GROUP_OVERRIDES` 在加载时把这两只的蛋组改回与雄性线一致的 **怪兽 / 陆上**，重新生成 `dex.json` 也不会被冲掉。
- 研究笔记描述优先取 **Let's Go 皮卡丘/伊布** 的 `zh-hans`（官方简体中文，151 只全覆盖），没有时依次回退剑盾、红版英文；
  抓取时会把换行、换页符与软连字符清洗成单行中文。原文来自官方游戏，PokeAPI 仅作整理。
- `tools/fetch-sprites.mjs` 把 151 张像素图下载到 `data/sprites/`（共约 120 KB），游戏运行时**不依赖任何外链**，
  国内网络也能离线加载；图片缺失时会自动回退到 jsDelivr 镜像。
- `tools/fetch-item-sprites.mjs` 把进化道具的**游戏内道具像素图**下载到 `data/items/`（8 张，约 11 KB），
  通信电缆借用第八世代「联系绳」的官方图标；本地缺图时同样回退 jsDelivr。
- `data/experiments.json` 是**手工维护**的专属实验内容（151 只、458 条）：每只 2–8 条，带 `gentle / standard / harsh` 档位；
  不足 5 条时由 `js/logic.mjs` 按强度补入基础三条。它不随 `fetch-data.mjs` 重新生成，调内容只改这个文件。
- 实验结果池保留在 `data/results/`：`base.json` 放基础三行为，`{dexId}.json` 放该物种专属行为；目前游戏**不加载、不展示**这些文案，仅保留数据供后续恢复。461 种行为 ×（40 生还 + 10 死亡）= 23,050 条，由 `tools/generate-experiment-results.mjs` 生成。

## 界面

移动优先的三段式布局：

- **顶部 HUD**：资金、经验糖果、声望、职级、研究笔记进度，右上角是倍速与菜单（玩法 / 职级 / 保存 / 离开火箭队）。
- **中间内容区**：底部 TAB 对应的页面，每页顶部有一块美术横幅——培育栏显示栏位里的宝可梦、实验室显示实验对象、围栏显示闲置宝可梦、研究笔记显示进度环、经营显示金币与道具。
- **卡片标记**：围栏里刚出生的个体没有编号；首次进入培育栏或实验室时才会分配 `#0042` 形式的编号，之后一直保留。该物种研究 100% 后，卡片背景会变为偏青灰的已完成色调，和其他卡片略作区分。
- **研究笔记页**：点研究过的格子会弹出物种详情，完成研究后可以读到该物种的研究笔记描述。
- **耐受度灰度**：卡片与详情里的精灵会随耐受度下降逐渐变灰；满耐受度彩色，耐受度 ≤1 时完全黑白。
- **动效**：培育栏繁育成功时两只精灵轻碰并冒出爱心；配对失败争斗时同样轻碰，但爱心变成**交战标志**（⚔），并带红色闪光；实验室执行实验后收起选择框，并让对应实验对象抖一下——**实验的耐受度损耗越高，抖动幅度、光晕与持续时间越强**。
- **底部 TAB**：培育 / 实验室 / 围栏 / 经营 / 研究笔记；「经营」上显示“现在就能交付”的订单数红点，「围栏」上显示正在被霸凌的个体数。
- **日志**：经营页底部的「日志 · 最近动态」显示最近事件，并**随存档保留**——刷新页面后仍能看到之前的动态。

手机上为全屏 App 布局（适配底部安全区），桌面浏览器里会收成一个居中的 App 框；弹窗在小屏上以底部抽屉式弹出。

## LLM 文案生产

一次性内容管线，不参与游戏运行时：

```bash
# 1. 本机生成 .env（不要提交；.env 已加入 .gitignore）
cp .env.example .env
# 编辑 .env，填写 DEEPSEEK_API_KEY

# 2. 查看剩余队列
node tools/llm-generate-results.mjs --list

# 3. 生成（可反复运行，已完成的池会跳过）
node tools/llm-generate-results.mjs --generate --concurrency 4

# 4. 把已完整生成的行为池合并进 data/results
node tools/llm-generate-results.mjs --merge

# 5. 全量测试
npm test
```

每个行为独立调用模型，生成 40 生还 / 10 死亡；这些文案目前只保留在数据中，游戏内暂停展示，死亡状态由逻辑统一提示。

### 模块分层

```
data / rules  ←  logic  ←  ui  ←  main
        rules  ←  save   ←  main
```

- `data` / `rules` 不依赖任何运行时状态，是最底层；数值、文案、静态表集中在 `rules.mjs`。
- `logic` 只做状态推进，不碰 DOM，也不关心存档存储细节。
- `save` 只做持久化，不依赖游戏行为，也不写迁移逻辑。
- `ui` 只读状态与 `logic` 的派生查询（`idleMons` / `penMons` / `deliverableOrders` 等），不重复实现规则。
- `main` 是唯一把各层装配起来的地方。

### 开发约定

- **不考虑向后兼容。** 存档结构、数据字段、函数签名、旧玩法逻辑，一律不做兼容层与迁移分支。
  - 改字段就直接改，不要写「旧档可能没有这个字段」的兜底。
  - 需要时直接升 `SAVE_VERSION`，旧存档会被 `deserialize` 判为 `null` 丢弃、重新开档；游戏里本来就有「重新入职」。
  - 不要保留旧存档 key、旧版本判断、`delete st.<旧字段>` 这类清理代码。
- 数值与文案集中在 `rules.mjs`；`data/` 是生成产物，手工修正走 `js/data.mjs` 里的覆盖表（例如 `EGG_GROUP_OVERRIDES`）。
- 一个改动同时更新：代码、`tools/test-*.mjs`、帮助弹窗、README。

### 隐性设定（只写进文档，不写进界面）

游戏里有一批**故意不向玩家明示**的设定，目的是让"研究"保持为需要自己观察和试错的过程。
界面只给结果与现象，不给公式、概率和判定条件；这些设定统一记录在这里，改数值时对照本表。

| 设定 | 界面表现 | 出处 |
|---|---|---|
| 蛋组未知 | 只显示 `？？？`，繁育成功或该物种研究 100% 才揭示 | `logic.eggGroupsDisplay` / `revealEggGroups` |
| 百变怪配种不揭示对方蛋组 | 对方的蛋组继续是 `？？？` | `revealEggGroups` |
| 耐受度上限与等级、性别挂钩 | 只有进了实验室才显示数值，培育栏/围栏只靠灰度暗示 | `rules.toleranceCap` / `ui.applyToleranceFilter` |
| 能力值（种族值）按研究进度披露 | 未披露项显示 `？？？`，**不显示披露进度计数** | `logic.revealedStats` |
| 个体值（IV） | 从不展示，只参与计算 | `data.calcStats` |
| 研究满 100% 后不再产出日志 | 之后的实验、死亡、处理都不进入实验日志，界面不解释原因 | `logic.logExperimentRun` / `logLabDeath` / `logLabProcess` |
| 实验的真实影响 | 只标资金与冷却，不预告耐受损耗、致死风险 | `logic.toleranceLoss` |
| 实验结果文案 | 暂时不展示；生还/死亡由真实结果决定 | `data/results/*`（暂停使用） |
| 配对失败的原因 | 条满才知道会不会打起来；界面不提前说明同性/蛋组不匹配 | `logic.compatibility` |
| 闪光 / 不孕不育概率 | 只显示结果（徽章/光晕），不写概率 | `rules.CONFIG.shinyChance` |
| 繁育遗传规则 | 不解释 IV 均值与性格继承 | `logic.createEgg` |
| 血统与近亲 | 数据已记录但**判定尚未启用**，界面不展示 | [docs/kin-penalty.md](docs/kin-penalty.md) |

> 原则：**新增机制时，说明性文字默认放 README，界面只呈现玩家能感知的结果。**
> 帮助弹窗目前仍保留了一部分数值说明（如闪光概率、霸凌人数阈值），后续会逐步按本表收敛。
