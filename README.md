# 火箭队模拟器 · 第一世代

> 你被“请”进火箭队的地下基地，替他们管理与运营抢来的宝可梦。
> 表面上，你是个听话的年轻研究员；暗地里，你在为那部尚未问世的“宝可梦图鉴”积累第一手资料。

基于 [PokeAPI](https://pokeapi.co/) 第一世代（#001-#151）数据的静态经营游戏：配种、孵化、养成、满足火箭队各部门的需求、扩建设施。纯前端、零依赖、无后端，可直接部署到 GitHub Pages。

## 游戏设定

**时间线**：大木博士还年轻，图鉴尚不存在，宝可梦研究刚刚起步。

**处境**：你在一次野外考察中被火箭队盯上。他们没有为难你——他们需要一位懂宝可梦的人，来管理基地里越堆越多的“战利品”。作为交换，你获得了自由出入培育区的权限，以及一间勉强能用的实验室。

**日常**：为抢来的宝可梦配对、孵化、养大，按各部门的需求交付。基地的运转离不开你，而你也离不开基地——至少在你写完那本笔记之前。

**暗面**：实验室才是你真正的目的地。表面上，你替火箭队管理培育栏、孵化器和实验台；实际上，每一场实验都是在替那部还不存在的图鉴补数据。实验对象的耐受度归零时，它们会被当作“损耗”放生——你把结论写进笔记，把尸体留在基地。

**部门**（订单来源，游戏内随机出现）：

| 部门 | 需求偏好 |
| --- | --- |
| 后勤部 | 什么都收，数量优先，等级要求低 |
| 研究部 | 博士自己的实验样品，偏爱稀有物种与特殊性格 |
| 警卫队 | 能打能扛，等级要求高 |
| 通讯部 | 电系宝可梦，用于干扰与窃听 |
| 走私组 | 稀有货，越难搞越值钱 |
| 外勤组 | 野外行动需要可靠的伙伴，属性对口优先 |

**胜利条件**：完成第一世代 151 个物种的图鉴研究。到那时，你既完成了火箭队的 KPI，也完成了自己的研究——剩下的，交给历史。

> 设定以本文档为准。游戏中已体现部门归属、订单类型、实验室与胜利条件；剧情对话、部门好感度、研究笔记文本等仅作背景设定，未全部实现。
> 已知缺口：传说 / 幻兽（#144~#146、#150、#151）目前没有获取渠道，等后续补充走私拍卖等设定；在此之前全图鉴在数学上不可完成。

## 玩法

1. **配种**：同一栏位放一雄一雌、蛋组有交集的宝可梦，2.5 天后产蛋。没有亲密度门槛，蛋组信息显示在卡片与详情里。
2. **孵化**：蛋在孵化器中倒计时，孵出的永远是家族**最初形态**（猫老大的蛋孵出喵喵）；孵化步数（`hatch_counter`）越高越慢，孵化器每级加速 10% 并 +1 蛋位。
3. **养成**：栏位中的宝可梦持续获得经验（训练场可加速），喂树果可快速加经验。
4. **进化**：升级自动进化；石之进化、通信进化需在详情页手动触发并消耗道具。
   - 通信进化（勇基拉 / 豪力 / 隆隆石 / 鬼斯通）需要「通信电缆」。
   - 伊布、皮卡丘、六尾、卡蒂狗等需要对应进化石。
5. **实验室（图鉴唯一解锁途径）**：把宝可梦放进实验台，消耗资金进行实验，累积该**物种**的研究进度。
   - **放进去就取不出来了**，只能继续实验，或手动放生。
   - 每只宝可梦有 100 点耐受度；实验会按隐藏的攻击 / 特攻参数扣除耐受度。
   - **实验窗口不显示进度与预计损耗，只标资金消耗**——具体影响要自己记录。
   - 耐受度归零：结算完本次进度后放生；若是「下一次实验会扣到负数」，则实验不生效（不给进度、不扣资金），直接放生。
   - 研究要求按稀有度（capture_rate）决定，越稀有越难：波波 40、梦幻 334。
6. **部门需求**：任意 / 属性 / 指定物种三类，按时交付得资金与声望；过期扣声望，也可主动回绝（-2 声望）。
7. **经营**：资金用于买蛋、树果、进化石与设施。市场每天刷新，需求物种的蛋更容易出现。
8. **胜利**：**151 个物种的图鉴研究全部完成**时结算，展示达成天数与经营数据。

## 数据

- `tools/fetch-data.mjs` 从 PokeAPI 抓取并压缩生成 `data/dex.json`（约 120 KB）：
  中文名、属地名、属性、种族值、特性、蛋组、孵化步数、成长曲线、捕获率、性别比例、进化链、25 种性格。
- `tools/fetch-sprites.mjs` 把 151 张像素图下载到 `data/sprites/`（共约 120 KB），游戏运行时**不依赖任何外链**，
  国内网络也能离线加载；图片缺失时会自动回退到 jsDelivr 镜像。

## 本地运行

ES 模块必须通过 HTTP 访问，不能直接双击 `index.html`。

```bash
node tools/serve.mjs 8123
# 浏览器打开 http://127.0.0.1:8123/
```

> 存档为 v2 格式；旧版存档（v1）会被直接忽略，不会读取。

## 测试

```bash
node tools/test-logic.mjs   # 逻辑层：300 天模拟、配种/孵化/进化/交付/存档/胜利条件
node tools/test-ui.mjs      # 视图层：DOM 桩驱动的渲染与交互（含“数值变化不重建 DOM”回归）
```

## 重新生成数据

```bash
node tools/fetch-data.mjs      # 图鉴数据
node tools/fetch-sprites.mjs   # 像素图
```

```
├─ js/

   ├─ test-logic.mjs
   └─ test-ui.mjs
```
